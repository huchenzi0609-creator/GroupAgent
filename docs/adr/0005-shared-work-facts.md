# 0005：聊天与执行共用任务事实

日期：2026-11-17。状态：已实现；本地回归与真实模型路由已验证，测试群发布另存运行记录。

## 问题

后台保存、执行并交付了工作，前台在穿插其他话题后却否认任务存在。短期聊天选择器只在部分词法条件下展示工作；空展示混淆了未查询、不可见、截断和确实无匹配。状态查询还沿用控制操作的旧版本比较，后台正常推进会导致读取冲突。

## 决策

- 以同一公开可见性查询生成工作索引、实时小摘要和详细查询。状态、近期工具活动、验证产物和原生交付接受情况来自持久记录；不解压执行检查点，不暴露推理或工具正文。
- 每轮提供少量活跃及近期工作摘要，独立于对话焦点。摘要声明时间、范围、计数及完整性，不自动让闲聊变成旧工作的续接。历史可按名称、状态、发起人及明确引用查询。
- 任务事实使用既有 `query_work` 语义分支，由后端重取并渲染；读取不 claim、恢复或新建工作，不使用写操作的旧 revision CAS。修改与取消继续保留原权限和版本保护。
- 原始工作状态保持原貌，恢复中的呈现独立表达。排队或未知发送不等于已接受，接受也不表示收件人已读。只有对应查询完整为空才能回答未找到匹配记录。
- 模型的普通自由回复遵循同一事实契约；不以新增关键词或自报布尔值声称任意文本都已形式验证。真实模型路由与确定性后端行为分别验收。
- 静默接收的媒体仅继承已存在的、同成员显式唤醒会话关联；不修改静默政策，不自动开始处理附件，也不跨成员延续会话。
- 元数据身份沿用统一 alias。元数据的内部来源 ID 依赖用于撤回与删除级联，不作为新工具权限或附件授权，不要求加载整个历史正文。

## 验证与部署

版本化合成对话覆盖创建两项工作、八轮其他话题、自然追问、执行与交付、质疑纠正及补图。另验证读取期间状态推进、完整空查询与截断、无重复执行、发送未知、群与私有主题隔离、来源撤回及身份 alias。

测试运行、合成与真实验收的界限见 [回归说明](../development/WORK_AWARENESS.zh-CN.md)。沿用现有数据库结构、依赖与持久数据；目标群采用单发送者源代码更新及原有备份和回退过程。
