# 0008 由模型决定下一步的 ReAct 循环

日期 2026-11-18，实施分支 `refactor/pot-react`。叠加 ADR0006 的共享
LangGraph 内核，替换 ADR0007 的前台语义预判与常规终审。

Pot 在一个模型会话里收到原始目标、可信对话关系、按需检索的事实和工具效果。
模型决定答复、静默、了解更多、修改目标、执行或委派。工具列表受真实权限
和功能控制，初始语义标签不决定工具准入。简短答复可以一次调用结束。
前台使用 `finish_turn` 明确可见答复和实际效果阶段。
已提交的动作需要与主机回执对应，错误的声明作为观察留在同一轮处理。
普通自然措辞仍由模型生成。后台文件和研究产物继续在交付前独立验证。

对话、定时目标和主动观察用同一内核实现，各自有独立会话上下文。
可信身份、范围验证、可见性、静默、原生送达回执、恢复、沙箱和单发送者
仍由主机执行。真实停止及明确静默可以优先生效。主动内容来源是可查的、
有版本的事实，不能扩大授权。影子模式记录判断及候选哈希，群消息全文不进入
观察记录。提供方临时失败可以退避重试，已提交的观察只产生一个投递标识。

定时规则由模型选择是已备好的文本还是到点应重新观察的目标。准备好的
明确提醒保留原文凭据，当前个人静默的用户仍可获得其明确交办的提醒。
全群静默延后发送。时间触发使用独立的短数据库事务，维护在批次边界让出。
实际时间、时区、发生状态和投递回执从持久事实读取。

模型可以通过工具提出版本化策略、在同一工作试用并加载已评测策略。
代码实验使用明确授权的开发源快照和不可改写的外部评测集，比较基线与候选，
产出绑定来源、镜像与结果的独立证据。核心实现变更通过单独的版本激活与发布。
工作层的策略建议和开发候选都不会获得新的工具权限。

迁移 017–019 扩展规则、发生记录、观察生命周期及演进版本，无历史补发。
已发送与未知的回执保留。上一版本使用经过源码校验的兼容镜像做回退，
只接管旧任务，暂停它无法可靠处理的新式队列。主动观察从启用点开始，
忽略历史积压，重启仍复用同一个启用点。测试群先启用影子观察和受控策略工具。

评测以可见行为、实际工具效果及故障后的状态为准。使用未参与提示词和
开发用例的合成场景，分开记录真实提供方、实际容器、真实数据库和本地通道。
